## Architecture and boundaries

- `modules/ai/contracts.ts`, `runtime.ts`, `provider.ts`, `ai.ts`: bounded provider protocol, default-off per-capability flags plus server kill switch, deterministic fallbacks, strict advisory output, server-side usage/cost/error metrics and atomic daily cost reservation. Never mutate property/listing facts. Provider gateway is optional; all local acceptance runs without real credentials.
- `modules/trust/rules.ts`, `trust.ts`, `worker.ts`: deterministic anti-fraud publication gate, contextual scan enqueue, leased/retryable jobs, multi-signal candidates, immutable confidence/reason records, admin human review with stale-snapshot fencing. Existing moderation decision flow remains authoritative.
- `apps/ai/raui_ai/duplicates.py`, `worker.py`: bounded JSON-in/JSON-out Python data worker for candidate scoring; never connects to DB or writes domain objects. Existing Node worker owns transactions, leases and provider integration.
- `modules/analytics/analytics.ts`: versioned authenticated event contract, daily HMAC pseudonyms with DB-generated keys, bounded retention, context-authorized seller aggregates, live-public market cohorts with minimum size; no raw visitor API.
- `009_ai_trust_analytics.sql`: additive tables/indexes/default-off flags only; no edits to applied migrations. Durable audit stays in existing audit module.
- `ai-trust.test.ts`, `ai-trust.integration.test.ts`, Python tests: real behavior, existing security tests retained. Root test runner/CI get the new suite and standalone trust-worker smoke.
- `common/openapi.ts`, `.env.example`, README and `PHASE4C_REPORT.md`: actual contracts, operation/flags, migrations, verification and forward-fix notes.

## Explicit safety decisions

AI suggestions require human confirmation and cannot be used as property facts or moderation decisions. Duplicate confidence produces candidates only: no merge/delete/link/unpublish. Risky text patterns require an independently audited reviewer disposition before approval; core checks always remain enabled. Human dispositions bind exact fact/media/rule snapshots and cannot silently carry across edits. Price-range foundations are indicative aggregates, require enough live public comparables and return insufficient-data explicitly. Market grouping is fixed locality/category/deal type, not arbitrary micro-cohorts. No raw prompts, model output, contact details, provider tokens or visitor identities enter usage/audit APIs.

Conservative thresholds/caps are versioned engineering safeguards, not claims of calibrated fraud probability or professional valuation. Provider certification and production rollout are later owner gates; optional provider absence does not block deterministic Phase 4C acceptance.
