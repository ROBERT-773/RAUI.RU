# Owner and publication moderation workflows

User authorized implementation using the latest full scenario, now preserved in docs/RAUI_ACCOUNT_SCENARIO_2026_10_08.md. That scenario supersedes older template conflicts: re-registration exclusion six months, indicative moderation targets about three days free / one day paid. Neither rule is activated in this UI deliverable. Moscow and Moscow Oblast remain the initial regions.

First bounded deliverable connects existing Property, Listing, Media and moderation APIs to usable web screens. Verified sellers create a property and draft with explicit category, region, address, coordinates, typed characteristics, deal, price and description. Save/resume listing drafts, upload supported photos, inspect processing state, edit offer fields after pausing active publication, and submit draft through processing to manual moderation. Preserve server authorization, current versions, CSRF and stable idempotency keys. Uncertain create outcomes retry frozen payloads without duplicate properties in the current page session. Unsaved edits are protected from navigation/media refresh. Current manual coordinates are editable; geocoding, map correction and automatic draft save remain future improvements.

Staff see pending cases, version-matched material, ready private images and known scalar characteristics. Text-only hints are advisory and make no accuracy claims. Decisions require a reason and explicit confirmation. Server verifies granted permissions and rejects stale/self review; browser does not confer rights. Refresh/retry failures honestly, preserving action keys.

No schema or API-domain changes. Proxy exposes only specific property/moderation paths and methods. Account link leads to private listings screen. Full scenario features not covered: six-object quota, registration/recovery approval, SMS provider acceptance, ownership evidence, paid entitlements/role conversion, complaints/post-publication blocks, expiry/cleanup, CRM/social/ESIA, bidding, bookings/insurance/transactions. Publication checks still enforce existing verified seller/media/property completeness. This branch is a candidate, not a complete public launch or deployment.
