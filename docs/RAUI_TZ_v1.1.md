# 3. ТРЕБОВАНИЯ К ФУНКЦИОНАЛЬНОСТИ

## 3.1. Роли пользователей

| Роль                   | Возможности                                                                    |
| ---------------------- | ------------------------------------------------------------------------------ |
| Гость                  | Просмотр каталога, поиск, карточки, отзывы                                     |
| Покупатель / Арендатор | Избранное, сохранённые поиски, чат, заявки, ипотека                            |
| Собственник            | Публикация объявлений (лимит — см. ниже), статистика, продвижение, верификация |
| Агент / Риелтор        | Неограниченные объявления, CRM, лиды, аналитика, рейтинг                       |
| Агентство              | Управление сотрудниками, сводная аналитика, интеграции                         |
| Застройщик             | Проекты, шахматка, аналитика, «Убери конкурента», закрытый чат                 |
| Админ                  | Полный доступ к платформе                                                      |
| Модератор              | Проверка объявлений, фото, жалоб, пользователей                                |
| Рекламодатель          | Управление рекламными кампаниями (кабинет — вторая очередь)                    |

**Лимит собственника:**
Собственник может иметь не более 1 активного объявления одновременно. После снятия, архивации или истечения срока объявления он может опубликовать новое. Лимит на количество публикаций в месяц — 3 (защита от спама). Для публикации большего количества — переход на платный тариф или смена роли на «Агент».

## 3.2. Регистрация и авторизация

- По номеру телефона + СМС.
- Через Госуслуги (верификация).
- Через ВКонтакте, Mail.ru, Сбер ID, Tinkoff ID.
- Email + пароль.
- 2FA для админов и модераторов.
- Face ID / Touch ID в приложении.

## 3.3. Личные кабинеты

Покупатель: избранное, сохранённые поиски, история, заявки, чат, ипотека, настройки.

Собственник: мои объявления, статистика, финансы, верификация, уведомления.

Агент: объекты, CRM (лиды, звонки, сделки), заявки, аналитика, финансы, рейтинг.

Агентство: сотрудники, объекты, аналитика, финансы, интеграции.

Застройщик: проекты, шахматка, аналитика, финансы, конкуренты, чат девелоперов.

## 3.4. Уведомления

Каналы: push, email, Telegram, SMS.

Типы: новый объект по поиску, изменение цены, новое сообщение, звонок, заявка, статус модерации, рекомендации.

Настройка: по типу и каналу отдельно в ЛК.

## 3.5. Поиск и карточка объекта

- Фильтры: тип, цена, площадь, этаж, комнаты, район, метро, тип дома, год, отделка, высота потолков.
- Поиск по карте с кластерами, изохронами.
- Сохранение поиска + уведомления.
- Карточка: галерея, видео, 3D-туры, характеристики, история цены, продавец, кнопки «Позвонить / Написать / Забронировать», похожие, жалоба.

## 3.6. Умный поиск (Smart Search)

- NLP: понимание естественного языка («двушка в Хамовниках до 20 млн с ремонтом»).
- Исправление опечаток, синонимы.
- Голосовой ввод (Speech-to-Text).
- Поиск по фото (Computer Vision).
- Уточняющие вопросы.
- Персонализация.
- Поиск по инфраструктуре (парки, школы).
- Похожие запросы.
- Поиск по ЖК.

## 3.7. Чат и коммуникации

- Встроенный чат покупатель ↔ продавец.
- Прикрепление файлов.
- Шаблоны сообщений (для агентов).
- Привязка чата к CRM.
- Интеграция с Telegram, WhatsApp.

## 3.8. Мобильное приложение

Базовое: поиск, фильтры, карта, push, чат, ЛК, избранное, сравнение.

Расширенное: CRM для агентов, приём звонков, ипотека, ИИ-помощник, офлайн-режим, Face ID, виджеты, Apple Watch, PDF, 3D/VR-туры, видеозвонки, AR-примерка.

## 3.9. Интеграции

Госуслуги, банки (Сбер, ВТБ, Альфа), amoCRM, Битрикс24, Telegram, WhatsApp, ЮKassa, СБП, ФНС, Росреестр, 1С, Google/Apple Calendar, Zoom, Яндекс.Карты, 2ГИС, Google Maps, СМС-шлюзы, email-сервисы.

## 3.10. Модерация и безопасность

- Автомодерация (ИИ) + ручная.
- Проверка фото, дублей, адресов, цен.
- Верификация через Госуслуги.
- Защита от мошенничества.
- Шифрование, SSL, 2FA.
- Жалобы и апелляции.

# 4. СЦЕНАРИИ ИСПОЛЬЗОВАНИЯ (USER FLOWS)

## 4.1. Регистрация и вход

1. Ввод телефона → СМС-код → выбор роли → заполнение профиля → ЛК.
2. Альтернативы: Госуслуги, ВК, Mail.ru, Сбер ID.
3. Восстановление доступа — по телефону / email.
4. Смена роли — через настройки, с ограничениями.

## 4.2. Публикация объявления

ЛК → «Разместить» → тип сделки → тип недвижимости → характеристики → адрес → цена (с рекомендацией ИИ) → фото → описание (ИИ-генерация) → контакты → верификация → публикация → модерация → публикация.

## 4.3. Редактирование / продление / продвижение

- Быстрое редактирование «за 15 секунд».
- Продление автоматическое / по кнопке.
- Платное продвижение: поднятие, выделение, «Убери конкурента».

## 4.4. Поиск и подбор

Базовый поиск, карта, сохранение, избранное, обращение (звонок / чат / заявка).

## 4.5. Личный кабинет по ролям

Детальные сценарии для каждой роли.

## 4.6. Уведомления

Настройка, получение, отключение.

## 4.7. Чат

Начало диалога, файлы, шаблоны, привязка к CRM.

## 4.8. Модерация

Автомодерация, ручная, жалобы.

## 4.9. Мобильное приложение

Первый запуск, поиск, push, ипотека.

## 4.10. Интеграции

Госуслуги, CRM, Telegram.

# 5. РЕКЛАМНЫЕ БЛОКИ И МОНЕТИЗАЦИЯ

## 5.1. Места размещения

- Главная: топ-баннер, промо-карусель, «Рекомендуем», «Новостройки», боковой, нижний.
- Поиск: баннер в топе, продвигаемые объявления, in-feed, sticky-баннер.
- Карточка: баннер агентства, «Ипотека», «Похожие», «Ремонт».
- ЛК: промо-блоки для продвижения, CRM, ипотеки, курсов.

## 5.2. Форматы

Баннеры, нативные блоки, промо-посты, видео, popup, email, push.

## 5.3. Кабинет рекламодателя

Каталог мест, покупка, загрузка баннера, модерация, статистика (показы, клики, CTR).

**Приоритет:** кабинет рекламодателя — вторая очередь. В MVP рекламу размещает и ведёт администратор через админку. Кабинет запускается при количестве активных рекламодателей > 20.

## 5.4. Модели монетизации

- Продвижение объявлений.
- Подписки для агентов.
- Платные лиды.
- Баннерная реклама.
- Партнёрские программы.
- Комиссия за бронь.
- API-доступ.
- **«Убери конкурента»** — эксклюзивное размещение на странице ЖК и в блоке «Похожие». Срок: 7 / 30 / 90 дней. Не скрывает конкурентов в общем поиске и на карте — только на странице конкретного ЖК и в блоке «Похожие». Стоимость зависит от ЖК и срока.

# 32. ПЛАН РАБОТ, ПРИОРИТЕТНОСТЬ И ЭТАПНОСТЬ

## 32.1. Принципы планирования

- MVP-first: сначала минимально рабочая версия — потом расширение.
- Бизнес-ценность: сначала то, что приносит деньги и пользователей.
- Зависимости: сначала фундамент (инфраструктура, БД, авторизация) — потом надстройки.
- Параллельность: дизайн, разработка, контент — идут параллельно.
- Тестируемость: каждый этап заканчивается тестированием и демо.

## 32.2. Приоритеты (MoSCoW)

### 🔴 MUST HAVE (без этого запуск невозможен)

- Регистрация и авторизация.
- Личные кабинеты (все роли, кроме рекламодателя).
- Публикация объявлений.
- Поиск и фильтры.
- Карточка объекта.
- Чат.
- Уведомления.
- Модерация (авто + ручная).
- Админка (базовая, включая размещение рекламы администратором).
- Модерационный кабинет.
- Платежи и продвижение.
- Юридический блок (152-ФЗ, cookie, оферта).
- Безопасность (SSL, 2FA для админов).
- SEO-база (robots, sitemap, мета-теги).
- Адаптивный дизайн.
- Мобильная версия сайта.

### 🟡 SHOULD HAVE (важно, но можно во второй волне)

- Мобильное приложение (iOS + Android).
- CRM для агентов.
- Умный поиск (NLP).
- Автоматизация (ИИ-модерация, генерация описаний).
- Рекламный кабинет рекламодателя (запускается при > 20 рекламодателей).
- Расширенная аналитика.
- Интеграции (Госуслуги, банки, CRM).
- B2B / API.
- Услуги вокруг недвижимости.
- Мультиязычность.

### 🟢 COULD HAVE (желательно, но не срочно)

- Социальные функции.
- Форумы, подкасты, вебинары.
- AR/VR-туры.
- Apple Watch, виджеты.
- White-label.
- Партнёрская программа.

### ⚫ WON'T HAVE (в первую версию не входит)

- Собственная разработка карт.

Документ включает 32 раздела:

- Функционал, сценарии, роли.
- Реклама, SEO, дизайн.
- Автоматизация, ИИ.
- Админка и модерация.
- Автотесты и мониторинг.
- Юридические, финансовые, инфраструктурные аспекты.
- Брендинг, маркетинг, поддержка.
- Проектные параметры.
- План работ, приоритеты, этапность.

Внесённые уточнения (v1.1):

1. Лимит собственника — 1 активное объявление одновременно, 3 публикации в месяц.
2. «Убери конкурента» — эксклюзив на странице ЖК и в блоке «Похожие», срок 7/30/90 дней, не скрывает конкурентов в общем поиске и на карте.
3. Рекламный кабинет — вторая очередь. В MVP рекламу ведёт администратор через админку. Кабинет запускается при > 20 рекламодателей.
