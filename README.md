# RAUI.RU

RAUI.RU — портал недвижимости для Москвы и Московской области.

Этот репозиторий инициализирован как базовый корень проекта для дальнейшей разработки по техническому заданию RAUI.RU.

## Планируемая архитектура
- Frontend: Next.js + React + TypeScript
- Backend: NestJS + TypeScript
- AI/Data workers: Python
- Database: PostgreSQL + PostGIS
- Search: OpenSearch
- Cache/Sessions: Redis
- Media: S3-compatible storage + CDN

## Структура
- `apps/` — приложения
- `packages/` — общие пакеты
- `docs/` — архитектура и документация

Текущий статус: инициализация репозитория.
