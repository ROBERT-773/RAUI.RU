# RAUI.RU — Second Brain

Эта папка — Markdown-база знаний, совместимая с Obsidian. **GitHub остаётся источником истины**. Обновляйте документацию через отдельные PR; не храните здесь пароли, ключи, персональные данные или секреты.

## Карта знаний
- [[01-Техническое-задание]] — действующее ТЗ и пользовательские подсказки.
- [[02-Архитектура]] — компоненты и важные документы.
- [[03-Агенты-и-роли]] — задачи и ограничения агентов.
- [[04-Релиз-и-проверки]] — критерии готовности, безопасность, откат.
- [[05-Журнал-решений]] — как фиксировать решения.

## Открыть в Obsidian
Клонируйте репозиторий RAUI.RU на компьютер. В Obsidian выберите **Open folder as vault** и укажите папку `knowledge`. Obsidian не обязателен для чтения файлов: все заметки доступны в GitHub. Для синхронизации используйте обычный Git, а не вторую независимую копию ТЗ.

## Принципы
1. Не копировать текст ТЗ в заметки: ссылки ведут к первоисточнику.
2. Статус задач сверять с GitHub, не отмечать «готово» без проверки.
3. Не давать агентам права на merge/deploy автоматически.
4. Один автор изменений на рабочую ветку; аудиторы работают read-only.
