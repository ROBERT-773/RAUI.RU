## Предпосылки
- В `package.json` RAUI.RU указан Node.js >=24 <25, pnpm 10.
- В корне есть `test:e2e` для API, но это не подтверждает наличие Playwright MCP.
- Codex параллельно выполняет независимый аудит issue #106; не редактировать его рабочую ветку.

## Подключение к Claude Code (вручную в доверенном окружении)

После проверки официальной документации и установленной версии Claude Code использовать команду из документации Microsoft. Типовой вариант:

```sh
claude mcp add playwright -- npx @playwright/mcp@latest
```

Для воспроизводимости после теста зафиксировать проверенную версию пакета вместо `@latest`. MCP-сервер получает возможность взаимодействовать с браузером: не предоставлять ему производственные cookies, токены, личные данные или доступ к админке.

## Проверка
1. Убедиться, что Claude Code распознаёт сервер `playwright` (например, через `/mcp`).
2. Запустить локальную тестовую среду RAUI.RU, используя тестовые данные.
3. Попросить агента открыть тестовый URL и проверить: главная, регистрация, форма публикации, пользовательские подсказки, ошибки валидации, мобильный viewport.
4. Сохранить результаты и скриншоты без персональных данных; завести issues для найденных дефектов.
5. Сверить с ТЗ и выполнить обычные тесты проекта; не считать MCP заменой существующим unit/integration/E2E.

## Ограничения
Не устанавливать зависимости в production, не коммитить credentials, не менять код в ветке Codex, не выполнять merge/deploy. Установка требует доступной среды Claude Code или другого MCP-клиента; запись в GitHub сама по себе её не выполняет.
