# React Bits — кандидат для RAUI.RU

Дата: 2026-10-11. Пользователь подтвердил название **React Bits**.

- Официальный проект: https://www.reactbits.dev/
- Репозиторий: https://github.com/DavidHDev/react-bits
- Назначение: библиотека готовых анимированных React-компонентов и визуальных эффектов для интерфейсов.
- Возможное применение: карточки недвижимости, переходы, интерактивные элементы и оформление страниц, если это улучшает удобство, производительность и доступность.
- До внедрения: проверить используемый стек фронтенда RAUI.RU, лицензию и зависимости, доступность для клавиатуры, prefers-reduced-motion, мобильную производительность и влияние на Core Web Vitals.
- Правило: не добавлять анимации ради анимаций; сначала UX и скорость.
- **Статус: внесён в список кандидатов, не установлен, не интегрирован и не протестирован.**

Связанные инструменты: [[06-Инструменты-к-подключению]] (Taste Skill, Playwright MCP).
