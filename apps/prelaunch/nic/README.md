# Ранняя регистрация RAUI.RU на хостинге NIC.RU

Комплект рассчитан на веб-сайт с корнем `…/raui.ru/docs`, PHP 8.x с PDO SQLite и приватным каталогом, доступным процессу PHP на запись. Для запуска требуется действующий HTTPS на имени, по которому посетители открывают страницу. Сервер хранит только email, телефон, UTC-время и версию согласия. Письма и SMS при регистрации не отправляются.

Этот пакет обновляет схему SQLite до версии 2. У существующей заявки `created_at` заполняется её исходным `consented_at`. У новых заявок обе отметки фиксируются при первой записи пары email и телефона. Повторная отправка сохраняет существующие значения.

## Обновление первого выпуска

Сделайте согласованную резервную копию SQLite и проверьте возможность её восстановления. В уже распакованном комплекте заменяются только приватные файлы. Сначала загрузите папку `raui-prelaunch-private/migrations` с файлами `001_initial.sql` и `002_created_at.sql`. Затем замените `store.php` и `operator.php` завершёнными копиями через переименование в том же приватном каталоге. Сохраните существующий `raui-prelaunch-private/data`. При первом обращении или запуске `operator.php check` PHP применит миграции в одной SQLite-транзакции. Прежний обработчик сможет завершить уже начатую отправку после обновления. Результат `Storage and write lock OK` позволяет переходить к обычной эксплуатации.

## Перенос заявок

Для переноса в другую систему используйте приватную команду ниже. Каждая строка JSONL содержит `email`, `phone`, `consented_at`, `consent_version` и `created_at` из одного согласованного состояния базы. Нормализованный email и телефон сохраняются точно, включая исходный плюс или апостроф. Команда записывает файл в тот же закрытый каталог `data/exports`.

```sh
php /путь/raui.ru/raui-prelaunch-private/operator.php export-jsonl
```

## Загрузка через файловый менеджер

1. Распакуйте ZIP в новом временном каталоге **выше** `docs`. Рядом с рабочим `docs` разместите целиком приватный `raui-prelaunch-private` с правами 0700. Каталог `data` PHP создаст сам. Разрешение `open_basedir` сайта должно охватывать этот конкретный приватный каталог. Если PHP его не видит, настройте разрешённый путь в панели своего сайта.
2. Из распакованной папки `docs` переместите **только** новую подпапку `raui-prelaunch-20261126` в действующий корень. Папки `activation`, резервные копии, ZIP и приватные файлы оставьте выше веб-корня.
3. Откройте `https://raui.ru/raui-prelaunch-20261126/landing.php`. Появятся заголовок и форма. Для проверки записи без контакта выполните с компьютера оператора команду ниже. Ожидается **HTTP 400** — запрос дошёл до транзакции SQLite, пустая заявка отклонена. Ответ **503** означает, что адаптер или приватное хранилище недоступны. В панели PHP проверьте `pdo_sqlite`, путь, владельца каталога и доступное место. Ответ **403** требует проверки доверенных серверных HTTPS-признаков хостинга и доменного имени. Приостановите переключение до успешной проверки.

```sh
curl -i -H 'Content-Type: application/json' --data '{}' https://raui.ru/raui-prelaunch-20261126/register.php
```

Сам PHP не доверяет `X-Forwarded-For`, `X-Forwarded-Proto` и другим произвольным заголовкам. Используются нормализованные сервером значения `HTTPS`/порта и `REMOTE_ADDR`. Если общий фронтенд хостинга передаёт один IP всем посетителям, лимит 30 запросов в минуту будет общим для такого адреса. Хостер может настроить восстановление фактического адреса на своей стороне. Общая квота базы — 300 запросов в минуту. При отсутствии PDO SQLite служба выводит 503; пути внутри сайта и временное файловое хранилище она не использует.

## Активация и возврат

Запишите, какой исходный индекс открывает `/`. До активации сделайте приватные резервные копии **обоих** `docs/index.php` и `docs/index.html` выше веб-корня и проверьте, что копии скачиваются и совпадают с оригиналами. В файловом менеджере перенесите оба исходных файла в приватный каталог резервной копии с сохранением имён. Перенесите `activation/index.php` в `docs/index.php`. Такой порядок работает и при приоритете `index.html` в настройках веб-сервера. Не переименовывайте старый PHP в `.bak` внутри публичной папки. Проверьте корень HTTPS и доступность ресурсов.

Чтобы вернуть прежний сайт, перенесите новый `docs/index.php` в приватный каталог этого релиза, затем верните из проверенной копии и `index.php`, и `index.html`. Переместите подпапку новой публичной версии выше `docs`, чтобы прекратить приём прямых заявок. Сохраните `raui-prelaunch-private/data` с уже принятыми контактами.

## Закрытая выгрузка

В консоли хостинга, по SSH либо как разовое задание планировщика панели запускайте CLI выбранной версии PHP. Подставьте фактический абсолютный путь из панели.

```sh
php /путь/raui.ru/raui-prelaunch-private/operator.php check
php /путь/raui.ru/raui-prelaunch-private/operator.php export
```

Файл появится в `…/raui-prelaunch-private/data/exports`. Скачайте его через закрытый файловый менеджер или SFTP. Экспорт выводит только имя файла и число строк. CSV содержит заголовки `email,phone,consented_at,consent_version` и UTF-8 BOM. Для телефонов и потенциальных формул начальный апостроф задаёт текст ячейки. Выгрузка работает в согласованной читающей транзакции. Операторская команда доступна только в CLI. Приватный каталог, БД, журнальные файлы SQLite и CSV храните за пределами любого веб-корня. Для резервирования живой базы используйте штатную согласованную резервную копию хостинга или SQLite Backup.
